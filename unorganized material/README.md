# Unorganized Material

Drop zone for raw material that has not been placed on the site yet —
photos, text drafts, product notes, screenshots, links, anything.

**No structure required.** Dump files here in whatever form they arrive.

## How this folder gets used

When there is new material here, ask an AI assistant to organize it, e.g.:

> Look at `unorganized material/` and add the new stuff to the website.

The assistant should then:

1. Read every file in this folder and work out what each one is.
2. Decide where it belongs on the site (which page, which section).
3. Build or update the actual site files in the repo root.
4. Move the processed source files into `unorganized material/_processed/`
   so it is clear what has already been handled.
5. Report anything it could not place, and ask rather than guess.

## Notes

- Reference for the previous Google Sites version of the site lives
